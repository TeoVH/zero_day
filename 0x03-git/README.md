# 0x03-git - Git Project Tasks

This folder contains the Git training tasks for the `0x03-git` project. It is part of my early learning in version control and software collaboration tools.

## Contents

- `bash/`: Contains basic bash script files.
- `c/`: Contains a sample C program file.
- `.gitignore`: Specifies files to be ignored by Git.
- `up_to_date`: A marker file to indicate sync with the remote repository.

## Key Concepts Practiced

- Initializing and cloning repositories
- Creating and switching branches
- Making commits and pushing to GitHub
- Using `.gitignore` properly
- Keeping local and remote repos in sync

## Notes

- All tasks follow specific instructions provided as part of my Git learning module.
- Changes are made following best practices, including commit messages and structured folder organization.
