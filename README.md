# Zero Day - Git Training Repository

Welcome to the Zero Day project repository. This repository was created as part of my learning journey with Git and GitHub. It includes exercises focused on basic and intermediate version control skills using Git.

## Project Structure

- `0x03-git/`: Contains all exercises and tasks related to Git and GitHub.

## Purpose

This repository is used to:

- Practice fundamental Git operations (clone, commit, push, branches).
- Learn and apply good version control habits.
- Understand how Git works in team and individual workflows.

## Skills Learned

- Using Git CLI (command-line interface).
- Managing local and remote repositories.
- Understanding `.gitignore`, `README.md`, and directory structure in real projects.
